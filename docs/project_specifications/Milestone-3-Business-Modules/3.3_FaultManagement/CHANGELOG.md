# Versioning Strategy

Semantic Versioning (SemVer):

- MAJOR: Breaking architectural or business changes
- MINOR: New features with backward compatibility
- PATCH: Bug fixes, optimizations, documentation updates

Format:

MAJOR.MINOR.PATCH

Example:

- 1.0.0
- 1.1.0
- 1.1.3
- 2.0.0
