# Versioning Policy

- **Major (X.0.0):** Breaking architectural or platform changes
- **Minor (x.Y.0):** New capabilities, review engines, framework
  support
- **Patch (x.y.Z):** Documentation improvements, bug fixes, prompt
  refinements
